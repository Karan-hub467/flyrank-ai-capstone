\# FE-03 React Movie Application — Submission Notes



\## Completed Application



Built a React-based movie application using AI as a development assistant.



The application includes:

\- Create Account form

\- MovieHub home screen

\- Movie search functionality

\- Popular movie cards

\- Movie year, genre, and rating

\- Responsive layout

\- Dark-themed UI



\## Prompts Used During Development



1\. "Build a React movie application with a create-account screen and a movie browsing screen."

2\. "Add movie cards with title, year, genre, rating, and search functionality."

3\. "Add responsive CSS styling for the movie application."

4\. "Make the movie application clean, simple, and easy to use."

5\. "Check the application for errors and make sure the React project builds successfully."



\## How AI Assisted



AI was used as a development assistant throughout the implementation. It helped structure the React application, create functionality, suggest CSS styling, and guide debugging and testing. The generated code was reviewed and tested locally before being committed to Git.



\## Manual Improvements and Refactoring



After reviewing the AI-generated implementation, I manually:

\- Adjusted the application styling and layout.

\- Added responsive behavior for different screen sizes.

\- Checked and corrected the account form behavior.

\- Tested the movie search functionality and no-results state.

\- Ran the production build and verified that the project compiled successfully.

\- Reviewed the final files before committing and pushing the FE-03 branch.
